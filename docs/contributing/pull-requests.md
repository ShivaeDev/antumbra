# Pull requests

Use an impact-focused title.

The body starts with `### Why?`: state the problem in one to three sentences.
Follow with `### How?`: state the approach in one or two sentences.

Add `### Decisions` only when the change makes meaningful tradeoffs, with one
bullet per decision. Add `### Callouts` only when a spot deserves reviewer
attention, with one bullet per callout.

Do not add file lists, test plans, or diff narration.
