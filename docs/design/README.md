guides own the relationships, acts, rationale, and recovery behavior within
each bounded topic. [`GLOSSARY.md`](../../GLOSSARY.md) is the short product-
language index that routes readers here; code and schemas own exact implemented
fields, states, and wire names.

- [Work and planning](work-and-planning.md) — authority, Voyages, course
  revision, Pieces, dependencies, and progress.
- [Attention and memory](attention-and-memory.md) — Boards, questions, mail,
  interruption, precedent, and smoothing.
- [Changes and delivery](changes-and-delivery.md) — Outcomes, durable landing,
  the Quay, and GitHub's mapping.
- [Agent identity, resources, and recovery](agent-recovery.md) — durable Agent
  identity, internal execution, Moorage, restart, siesta, and reclamation.
- [Renderer data layer](renderer-data-layer.md) — how the web UI receives fed
  snapshots and one-shot answers from the bridge, and how a view adopts them.
